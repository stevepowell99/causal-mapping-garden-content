What questions can you answer with causal mapping? 

What kind of object is a causal map and how do you answer questions with it?

The chapter after this one, [[010 Individual questions -- introduction ((questions-introduction))]], is a catalogue: one page for each question you can put to a causal map. 

## A map you can query

Coding narrative data leaves you with a table of links. A table can be interrogated. See [[010 Causal mapping produces models you can query to answer questions ((query-models))]] and [[The product of (causal) qualitative coding can be a model you can query ((model))]]. 

[[216 Outputs of QDA ((qda-outputs))]] puts causal mapping alongside other QDA approaches.

## What follows from what

A map shows that somebody said A influenced B, and somebody said B influenced C. Whether you may go on to say that A influences C is a venerable argument: [[700 The most controversial feature of causal maps is transitivity ((transitivity))]] and [[The transitivity trap ((transitivity-trap))]].

Beyond transitivity, [[705 Ways to causal inference ((ways-to-inference))]] surveys the routes that lead from a map to a claim about the world. [[712 We can reason about causal maps using a logic of evidence ((logic-of-evidence))]].  [[750 Causal maps are knowledge graphs, but with wings ((knowledge-graphs))]] connects this business to the knowledge-graph literature.

## Whether to believe the answer

Every query returns some result or ogher. Whether that answer is worth putting in a report depends on several things. [[902 Quality assurance at each step of the causal coding workflow ((quality-assurance))]] works through the workflow stage by stage. [[910 Assessing quality or robustness of evidence for a causal link based on a bundle of coterminal causal claims ((assessing))]] narrows down to a single link and asks how strongly it is supported.

Finally, [[760 Automating the standard questions -- slide creation functions ((scfs))]] shows how MapCat and the Causal Map app can help you decide which analyses you need, and run them for you.
